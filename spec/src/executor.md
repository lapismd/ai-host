# Executor

The executor adapts acpx, applies advertised session capabilities, and hosts
the application-tool MCP shim. Cursor ACP advertises only HTTP and SSE MCP, so
the broker also exposes Streamable HTTP `lapis-tools`. It keeps acpx types
inside this package.

## Requirements

| ID         | Requirement                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AH-ACP-001 | When an ACP session does not advertise `thinking` or `effort`, the host MUST keep the session usable with the agent default. It MUST NOT fail session start solely because the requested thinking control is unavailable.                                                                                                                                                                                                                                                                                                                                                                                       |
| AH-ACP-002 | ACP model discovery MUST first read a matching live persistent session when one is available, then a caller-identified persisted session without starting or closing another runtime. Only when neither exists may it read the agent's model status from a disposable one-shot session and close that session without persistent state. Cleanup MUST tolerate agents that do not advertise `session/close` without turning a successful listing into a failure.                                                                                                                                                 |
| AH-ACP-003 | The host MUST accept model, thinking, and a first-class `agent` on ACP start, default the agent to `codex`, pass that name and model to acpx `ensureSession`, and apply thinking through the first advertised `thinking`, `effort`, or `reasoning_effort` configuration key only.                                                                                                                                                                                                                                                                                                                               |
| AH-ACP-004 | `listAcpModels` MUST return each raw agent model id plus a structured entry with `label` and optional badges. Cursor bracket attributes MUST become a short label and Fast or Low/Medium/High badges. Session start MUST still receive the raw id.                                                                                                                                                                                                                                                                                                                                                              |
| AH-ACP-005 | A host `resumeSessionId` MUST be the acpx `sessionKey` for the stored binding. `ensureSession` MUST NOT send that host id as acpx `resumeSessionId`, because that field is an ACP `session/load` id and a mismatch MUST NOT fail resume with Invalid params. A resumed host session MAY receive a non-negative safe `sequenceBase`; the executor MUST emit its next frame above that base and MUST NOT reduce an existing session counter.                                                                                                                                                                      |
| AH-ACP-006 | When ACP start metadata includes a compact `availableSkillsManifest` with no host filesystem paths, the host MUST append it as acpx `sessionOptions.systemPrompt.append`. A path-bearing or non-manifest value MUST be omitted.                                                                                                                                                                                                                                                                                                                                                                                 |
| AH-ACP-007 | When ACP start metadata includes a path-free `sessionBootstrap` string, the host MUST append it with the skills manifest without requiring an application-specific wrapper marker. A path-bearing bootstrap MUST be omitted. The host MUST NOT persist that text.                                                                                                                                                                                                                                                                                                                                               |
| AH-ACP-014 | Disposable agent discovery MUST return the complete validated ACP session configuration-option catalog alongside model entries, preserving option ids, categories, current values, and selectable values so controller consumers can render model and thought-level choices without reading provider files. Unknown option shapes MUST be omitted.                                                                                                                                                                                                                                                              |
| AH-ACP-008 | An embedding host MUST be able to reserve a caller-selected ACP session id and begin initialization without awaiting agent startup. Deferred initialization MUST begin in a later event-loop task so the embedding host can flush its native response before an agent calls back into a shared loopback server. Prompts issued while that initialization is pending MUST wait for the same session, pending prompts MUST be cancellable or closable, and an initialization failure MUST emit one sequenced runtime error. The existing awaited start operation MUST remain available for standalone transports. |
| AH-ACP-009 | An embedding host MUST be able to reserve an ACP run id and acknowledge a prompt before beginning the turn in a later event-loop task. Deferred prompt failures MUST be emitted as sequenced runtime errors, while the existing awaited prompt operation remains available for standalone transports.                                                                                                                                                                                                                                                                                                           |
| AH-ACP-010 | A restricted ACP session MUST run as a one-shot session in an isolated temporary working directory, omit every external and application MCP server, reject permission requests without waiting for renderer input, and remove its temporary state when the session closes. The normal persistent ACP path MUST remain unchanged.                                                                                                                                                                                                                                                                                |
| AH-ACP-011 | A persistent ACP session MUST support provider-neutral model and thinking reconfiguration through advertised config keys. Model changes MUST use `model` and verify the effective status; thinking MUST use the first supported `thinking`, `effort`, or `reasoning_effort` alias. Unsupported or unverifiable fields MUST return structured results without discarding the session.                                                                                                                                                                                                                            |
| AH-ACP-012 | ACP agents MUST be selected through a host-owned registry of validated enabled identifiers. Missing selection defaults to Codex; blank, unknown and disabled identifiers MUST fail. Discovery MUST expose identifiers, labels and MCP transport without exposing commands, and configured command overrides MUST pass only to acpx.                                                                                                                                                                                                                                                                             |
| AH-ACP-013 | Permission responses MUST match a supported outcome offered by the runtime, except cancel. Pending requests MUST settle once on response, timeout, cancellation, close, host shutdown or expired controller disconnect; duplicate, ambiguous and unknown requests or outcomes MUST fail closed.                                                                                                                                                                                                                                                                                                                 |
| AH-MCP-001 | Protocol v3 MUST add authenticated application-tool bridge open, response, close, call, and cancellation messages while preserving protocol-v2 agent fallback without tools. The host MUST expose tools through an official-SDK stdio MCP shim backed by a token-authenticated ephemeral `127.0.0.1` broker, reserve `lapis-tools`, keep credentials out of arguments and durable state, and cancel in-flight calls when the owning connection closes.                                                                                                                                                          |
| AH-MCP-002 | ACP stdio MCP projections MUST include `type: stdio` plus required `name`, `command`, `args`, and `env`. Agents that skip invalid MCP items MUST still receive `lapis-tools`.                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| AH-MCP-003 | Cursor ACP sessions MUST receive `lapis-tools` as official-SDK Streamable HTTP MCP with `type: http`, a `127.0.0.1` URL, and bearer headers. Other ACP agents MUST keep the stdio projection. The host MUST NOT persist those credentials.                                                                                                                                                                                                                                                                                                                                                                      |
| AH-MCP-004 | The loopback tool broker MUST bind an ephemeral port by default and MUST let an owning host select a valid loopback TCP port when its runtime cannot bind port zero correctly. The selected port MUST apply to both WebSocket and Streamable HTTP projections.                                                                                                                                                                                                                                                                                                                                                  |
| AH-MCP-005 | A Web-standard host MUST be able to attach the authenticated Streamable HTTP handler to its own loopback server and advertise that server without starting broker-owned HTTP or WebSocket listeners. The attached route MUST preserve bridge ownership, bearer authorization, tool snapshots, calls, and cancellation.                                                                                                                                                                                                                                                                                          |
| AH-MCP-006 | The default stdio `lapis-tools` contribution MUST resolve its tracked MCP shim launcher relative to the AI Host package, never relative to the embedding process entrypoint or current working directory. Source-imported and built CLI hosts MUST therefore advertise the same package-owned launcher.                                                                                                                                                                                                                                                                                                         |
| AH-MCP-007 | An embedding executable MUST be able to supply the complete command and argument vector used to launch the stdio MCP shim. Credentials MUST remain in the child environment, and the default package-owned Node launcher MUST remain unchanged when no override is supplied. Native Codex launches MUST forward bridge environment variable names through MCP `env_vars` and mark the requested application bridge required, preventing turns from silently starting without their tools.                                                                                                                       |

The executor exposes optional read-only session enumeration for the standalone operator CLI. It reuses live session status and does not expose content.

Embedding controllers can resolve an agent launch command through the public library.
Explicit argv remains unchanged; absent overrides use the installed acpx registry,
including its configured adapter package range. Consumers must not invent an extra
global binary requirement for the same registered agent.
